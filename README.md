# Trans-it

Application de référence en hépato-gastro-entérologie (fiches, médicaments, scores cliniques).

Site statique : `index.html` + `assets/` (images). Aucune dépendance, aucun build nécessaire — déployable tel quel sur Netlify, GitHub Pages, ou tout hébergeur statique.

Version de consultation en lecture seule (les modifications se font sur la version privée de l'application).
